      Ayuda

      • Puedes conectar hasta tres LEDs.
      • Cada LED usa una resistencia para protegerse.
      • La pata corta del LED va a GND.
      ¿Qué es un pin digital?

      Es una conexión que Arduino puede utilizar para enviar señales digitales, como las que sirven para controlar un LED.

      ¿Para qué sirve la resistencia?

      Ayuda a limitar la corriente que pasa por el LED para protegerlo. En este circuito mide 220 Ω (ohmios).

      ¿Qué es GND?

      Es la conexión de referencia a tierra que permite completar el circuito.

      ¿Qué es el ánodo?

      Es el terminal positivo (+) del LED. Es la pata más larga.

      ¿Qué es el cátodo?

      Es el terminal negativo (−) del LED. Es la pata más corta.

      Cómo quieres trabajar

        Modo libre: escribe tu propio programa, carga ejemplos y experimenta con tus LEDs.

        Más información
        • Verifica tu código antes de ejecutarlo.
        • Usa digitalWrite(pin, HIGH) para encender y LOW para apagar.
        • Cambia el número de delay() para cambiar la velocidad: 1000 es un segundo.
        • El pin 13 también controla el LED L de la tarjeta.
